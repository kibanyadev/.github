# 基盤屋 · Kibanya

**Small tools for the platform layer.**

</div>

---

Kibanya is where [César Arroba](https://github.com/cesararroba) builds tools for the platform
layer: the infrastructure other software runs on. Exporters, infrastructure checks, and the small
pieces that keep cloud systems in order.

基盤屋 (*kibanya*) is how Japanese engineers might say "the platform person". 基盤 (*kiban*) is
the foundation, the part you don't see and can't skip. 屋 (*ya*) is a trade, or the shop where
it's practiced.

## Around here

- Each tool is small, does one job well, and says clearly what it doesn't do.
- Security reports go through the private **Report a vulnerability** link on each repository's
  Security tab.
